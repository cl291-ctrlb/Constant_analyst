# 📊 Power BI Tutorials & Reference Materials

This folder contains **Power BI tutorials**, **reference guides**, and practical resources to help build interactive dashboards and gain insights from data.

---

### 📌 What's Inside
- ✅ **Tutorials**: Step-by-step instructions on how to use Power BI for importing data, cleaning, modeling, and visualizing.
- 📄 **Reference Sheets**: DAX formulas, visuals guide, and tips for designing professional dashboards.
- 💼 **Case Study Insights**: Real-world scenarios with visual reporting techniques.

---

### 🛠️ Key Power BI Skills Covered
- Importing data from Excel, CSV, databases, and web  
- Data transformation using Power Query  
- Data modeling: relationships, cardinality, star schema  
- Writing DAX formulas for calculated columns and measures  
- Creating visuals: bar, pie, line, slicers, maps, and more  
- Designing interactive and responsive dashboards  
- Publishing reports to Power BI Service

---

### 📁 Folder Structure
- `/Tutorials`: Guided Power BI .pbix files or documentation  
- `/References`: DAX cheat sheets, formula examples, and layout templates  
- `/Visual Examples`: Screenshots or exported dashboards (PDF/PNG)
