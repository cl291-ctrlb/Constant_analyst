# 📊 Tableau Tutorials & Reference Materials

This folder contains **Tableau tutorials**, **reference guides**, and visualization resources to help build effective dashboards and extract insights from data.

---

### 📌 What's Inside
- ✅ **Tutorials**: Step-by-step files to learn Tableau fundamentals and advanced visualization techniques.
- 🧾 **Reference Sheets**: Quick guides on calculated fields, filters, parameters, charts, and formatting tips.
- 📈 **Visualization Samples**: Sample dashboards built using public datasets or case studies.

---

### 🛠️ Key Tableau Concepts Covered
- Connecting to different data sources (Excel, CSV, SQL, etc.)  
- Data preparation and cleansing in Tableau  
- Creating charts: bar, line, area, scatter, pie, maps, and more  
- Using filters, parameters, and calculated fields  
- Designing dashboards with interactivity and storytelling focus  
- Publishing to Tableau Public (if applicable)

---

### 📁 Folder Structure
- `/Tutorials`: Tableau workbook files (`.twb` / `.twbx`) and notes  
- `/References`: Formula sheets, shortcut lists, and formatting tips  
- `/Dashboards`: Completed dashboard examples (with dataset sources if available)
