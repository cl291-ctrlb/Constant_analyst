# ☁️ Cloud Tutorials & References (AWS & Azure)

This folder contains **cloud computing tutorials** and **reference materials** for working with **Amazon Web Services (AWS)** and **Microsoft Azure** — two of the leading cloud platforms.

---

### 📌 What's Inside
- ✅ **Tutorial Notes**: Key cloud concepts, services, and commands
- ☁️ **Platform Overviews**: AWS and Azure service comparison and use cases
- 🛠️ **Hands-on Labs**: Sample workflows for storage, compute, and data hosting

---

### 🛠️ Key Topics Covered

#### 🟧 **AWS**
- EC2 instance setup and SSH connection  
- S3 bucket creation, file upload/download  
- IAM roles and permission management  
- RDS basics for database hosting  
- CloudWatch monitoring and billing overview

#### 🔵 **Azure**
- Azure Portal overview  
- Resource groups and virtual machines  
- Blob storage operations  
- Azure SQL Database basics  
- Azure cost management and service tiers

---

### 📁 Folder Structure
- `/AWS`: Notes, screenshots, and commands for Amazon Web Services  
- `/Azure`: Tutorials and examples for Microsoft Azure  
- `/References`: Comparison charts, cheat sheets, and summaries
